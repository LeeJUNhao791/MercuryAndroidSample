### 2. 眼镜 AR 专项检查

请检查以下常见遗漏，每项给出发现的问题：

- **双目显示一致性**：`mBindingPair.updateView { }` 是否用于所有需要同步双眼的视觉更新
- **焦点系统完整性**：是否所有可交互视图都注册了 `FocusInfo`；`initFocusTarget()` 是否在 `onCreate` 中调用
- **触摸板事件处理**：`repeatOnLifecycle(Lifecycle.State.RESUMED)` 是否正确使用；双击是否映射为 `finish()`
- **焦点状态恢复**：页面切换后焦点状态是否需要保存和恢复
- **RecyclerView 交互**：`itemAnimator` 是否禁用；`StartSnapHelper` 是否正确配置
- **眼镜端与手机端分离**：眼镜端功能是否正确使用 `BaseMirrorActivity`，手机端功能是否使用 `BaseEventActivity`
- **3D 视觉效果**：`make3DEffectForSide(view, isLeft, hasFocus)` 是否正确使用
- **设备兼容性**：`DeviceUtil.isX3Device()` 是否用于 X2/X3 差异化功能判断

### 2.1 X2/X3 设备差异检查

如果 Tech Spec 涉及以下功能，需要检查是否正确处理了 X2/X3 差异：

| 功能 | X2 支持 | X3 支持 | 是否需要设备判断 |
|------|---------|---------|----------------|
| `SlideUpwards`/`SlideDownwards` | ❌ | ✅ | 必须 |
| 双指手势 | ❌ | ✅ | 必须 |
| VGA Camera (640x480) | ❌ | ✅ | 必须 |
| `filterMode` 设置 | ❌ | ✅ | 必须 |
| 传统 MIC `setParameters` | ✅ | 部分 | 建议兼容 |
| 新的 MIC API | ❌ | ✅ | X3 专用 |
| BLE 稳定连接 | 部分 | ✅ | 建议 |

检查点：
- [ ] Spec 中是否标注了哪些功能是 X3 独占的
- [ ] X3 独有功能是否有设备判断和 X2 降级方案
- [ ] Spec 是否说明了在 X2 设备上的替代交互方式

### 3. 遗漏检查

请检查以下通用遗漏：

- **并发场景**：快速点击、页面切换中的竞态条件是否有处理
- **数据一致性**：乐观更新失败后是否有回滚策略
- **生命周期**：configuration change 后状态是否恢复（眼镜设备旋转）
- **权限处理**：运行时权限申请失败后的降级方案（尤其相机、语音）
- **网络状态**：无网络时的缓存策略和降级处理
- **边界数据**：空列表、超长列表、分页边界（第 0 页 / 最后一页）
- **错误恢复**：API 重试机制、重试次数限制、退避策略
